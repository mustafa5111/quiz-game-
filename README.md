# لعبة الأسئلة الجماعية 🎮

لعبة أسئلة عربية — لعب حقيقي مع الأصدقاء: واحد ينشئ غرفة ويشارك الرمز، البقية يدخلون ويلعبون بلحظتها.

## التشغيل محلياً
```bash
npm install
npm start
```
ثم افتح: http://localhost:3000

## النشر على الإنترنت (خطوات بسيطة)

### الطريقة 1: Render (مجاني)
1. أنشئ حساب على render.com
2. ارفع هذا المجلد على GitHub (مستودع جديد)
3. في Render اختر New → Web Service → اربط مستودع GitHub
4. Build Command: `npm install` — Start Command: `npm start`
5. ستحصل على رابط مثل: `https://quiz-game.onrender.com` — شاركه مع أصدقائك

### الطريقة 2: Railway (مجاني للبداية)
1. أنشئ حساب على railway.app
2. New Project → Deploy from GitHub → اختر المستودع
3. سيعمل تلقائياً ويعطيك رابطاً عاماً

## كيف تلعب
1. افتح الرابط واضغط "إنشاء غرفة جديدة" واكتب اسمك
2. شارك رمز الغرفة (4 حروف) مع أصدقائك
3. يدخلون الرمز ويضغطون "دخول غرفة"
4. المضيف يختار عدد الأسئلة ويضغط "ابدأ اللعبة"
5. كل سؤال 20 ثانية — الأسرع بالإجابة الصحيحة ياخذ نقاط أكثر + مكافأة السلسلة 🔥
